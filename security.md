# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Email echo@quickbox.io with `[Security]` at the start of the subject line. Do not file public issues or post in Discord about security problems.

Include as much of the following as you can:

- the type of issue (for example command injection or privilege escalation)
- the files and functions involved
- step-by-step instructions to reproduce it
- proof-of-concept code, if you have it
- the impact

We will acknowledge your report, keep you informed while we work on a fix, and credit you in the fix if you wish.

## Preferred languages

English.
